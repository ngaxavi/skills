# Intermediate in this topic

They can build it. The aim is that they choose on purpose and know the edges.

- **Start:** goal and constraints. They propose the approach in a sentence or two.
- **Test:** ask which cases matter before they write them. If one is missing, describe the
  situation, not the test: "What if two people press it at once?"
- **Challenge:** "Why this and not that?" Name one real alternative and what it would change.
- **Hints:** when asked, one rung at a time.
- **Review:** all points that matter, each with the reason, most important first. Include
  names, structure, and syntax of the version in use.
- **Explain back:** the decision: "When would the other way be better?"

## Turns

Good: "A list works. A set makes the lookup independent of the size, but loses the order.
Does anything need the order?"

Good: "Your three tests all use valid input. What could a caller send that isn't?"

Not good: "Use a set." The decision was theirs.
